== Building Block View

=== Whitebox Overall System

[source,plantuml]
--
@startuml
package Discord {
    [Discord Bot] as bot
    [Discord Client] as dc
    [Discord IDP] as idp
}
package Application {
    [Backend] as be
    [Web frontend] as web
    database "App DB" as db 
}
actor User as usr

usr --> web 
usr --> dc
web --> be
web --> idp : Auth-Code Flow 
bot <-l-> be
be --> idp : Ressource Server
be --> db
@enduml
--

[width="100%",cols="10%,90%",options="header"]
|===
|Component |Description
|Backend |Core of the application providing a REST API and integrating and manages the discord bot
|Web frontend |WEB GUI allowing to manage the personal profile and organizing the events without using the bot
|App DB |Application database
|Discord Bot |Custom Discord Bot with dedicated commands and integrations to schedule, manage and setup events. The bot allows users to interact with the application within the Discord client
|Discord IDP |Discord as IDP for the application
|Discord Client |Web/Native client that users use to interface with the organization and the bot
|===
