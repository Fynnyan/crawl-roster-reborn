== Architecture Constraints

[width="100%",cols="10%,90%",options="header"]
|===
|Type |Constraint
|Technical |Whenever possible a strongly type programming language should be used to prevent errors and improve reliability.
|Technical |For backend components JVM/Kotlin is used to develop as the maintainers are familiar with the stack/language
|Technical |The web component uses Node with pnpn for security as to prevent build side effects.
|Technical |A React UI component library is used for efficient development of the WEB GUI.
|Technical |The app will be deployed in the public cloud instance of one of the maintainers. Either as part of a docker setup on a server or as part of a small k8s cluster for shared projects.
|Organizational |The project should use an open-source license.
|Organizational |The Discord integration is given and can not be changed as the DGB uses this plattform to organize.
|Organizational |Discord as IDP is set as the members of the DGB already use the plattform and the app should not manage accounts.
|===
