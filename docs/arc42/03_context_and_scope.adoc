== Context and Scope

[plantuml]
----
skinparam packageStyle rectangle

"User / GM / Admin" as usr

package Crawl-Roster {
    [Crawl-Roster Core] as cr_be
    [Crawl-Roster Web] as cr_web
}
[Discord] as disc
() "Discord IDP" as idp
() "Discord client" as dc
() "Discord Bot API" as api

disc -u- idp
disc -r- dc
disc -l- api

usr --> cr_web : direct interaction\n with the app,\naccess to non bot features
usr --> dc : interaction with the\n Discord guild\nsee events,\n join them,\n coordinate groups

cr_web --> cr_be
cr_web --> idp : Login via Discord

cr_be <--> api : Data sync\n and interaction
cr_be --> idp : Authenticate and\n Authorize User
----

|===
|Component | Description
|Crawl-Roster Web | Website that provides a web view for the user and provides access to functionality that has no place in the context of the bot.
|Crawl-Roster Core | Core of the system that implements the business logic, persistence and integrates with the Discord APIs
|Discord IDP | The app doesn't implement their own IDP, is connected to discord via a dedicated OIDC client.
|Discord Bot API | The discord Bot API that is integrated by the core component. The API is used to interact with the dedicated bot and sync the date between the two systems
|Discord Client | The web or native client of Discord.

The guild has it's own Discord Server where they organize the community and the events.

Users can see the the scheduled events, join an Event and a group within an event.
|===
